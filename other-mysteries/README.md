# Other mysteries

> *New here? See the [README](../README.md) for the overview and the [glossary](../GLOSSARY.md) for the ID/tag conventions (`K13`, `[#89]`, `H27`…).*

The Spider Dream Mystery doesn't exist in a vacuum. This folder holds the **neighbouring RDR2 mysteries** the investigation touched, each in its own file. They are **not steps in the spider trail** — the [verified-trail boundary](../CLAUDE.md#the-verified-trail-boundary--do-not-chase-speculation-past-it-read-this-before-theorising) applies — but each is documented to the same standard (tagged claims, graded sources, stable IDs).

For the raw game-file and script readouts behind many of these, see [`../datamining/`](../datamining/README.md).
